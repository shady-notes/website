You can put an image in a note without leaving the shade. Paste it or drag it
in, and Shady Notes saves it as a file and links it from the note. This has
worked since v2.5.0.

## Paste a screenshot

Take a screenshot to the clipboard with ⌃⇧⌘4, then click in a note and press
⌘V. The image appears where the cursor is.

## Drag from Finder

Drag an image file from Finder into the note. It lands at the point where you
drop it.

## Where the image goes

Either way, Shady Notes saves the image in your vault's attachments folder and
adds a link like this to the note:

```
![[screenshot.png]]
```

That is the same wiki-link syntax Obsidian uses, so the image shows up in both
apps. The image is an ordinary file in your vault, so it is backed up and
synced along with your notes.

## Resize it

Drag a corner handle of the image to make it smaller or larger in the note.

## Look closer

In read-only mode, click an image to open it in a preview window you can zoom
into. That is handy for a screenshot full of small text.

Next time you take a screenshot for a note, paste it straight in. Get Shady
Notes from [the download page](https://shadynotes.app/download).
