Preferences has eight tabs. This page maps what lives where; the pages linked
from each section explain the settings in context.

Open Preferences from the toolbar **…** menu or the menu bar icon.

## Appearance

Scroll direction and trigger zone depth · Esc closes the shade · launch at
startup · awning style, tab width and inactive opacity · window material ·
transparency for shade, sticky notes and window mode · editor background tint ·
sticky note border and collapse snap · chrome border width · workspace dots.

→ [Appearance](/customising/appearance/)

## Workspaces

One row per workspace: name, colour, assigned file tree, home page, visible and
active flags.

→ [Workspaces](/concepts/workspaces/)

## Editor

The largest tab. Fonts and sizes · editor margin · code block wrap, width,
language header, line height and colours · checkbox style and colour · automatic
continuation · parent checkbox tracking · line numbers and whitespace per mode ·
table lines, stripes and auto-format · attachments folder · image resize step ·
multi-image drop · animate GIFs · preview backend.

→ [Editor settings](/customising/editor-settings/)

## Where settings are stored

In macOS preferences, not in your vault. Copying the notes folder to another Mac
brings the notes, not the configuration.
