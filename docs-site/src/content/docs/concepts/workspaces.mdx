A **workspace** is a working context: a colour, a name, an assigned folder, a
home page, and its own [group stars](/organising/starred/). Switching workspaces switches what the
sidebar shows and which notes you're looking at, without touching anything on
disk.

<Image src={imgWorkspaceDots} alt="The workspace strip in the toolbar: five coloured pills, the active one larger and highlighted." />

Workspaces appear as coloured pills. Click one to switch, or cycle with
<kbd>⌥⇥</kbd> and <kbd>⌥⇧⇥</kbd>.

:::note
<kbd>⌥⇥</kbd> moves between **workspaces**. <kbd>⌃⇥</kbd> moves between **tabs**
inside the current one. They are easy to mix up.
:::

## What a workspace holds

| Property | What it does |
|---|---|
| **Name** | Defaults to "Workspace N" |
| **Colour** | From a 20-colour palette; tints the pill and the app icon badge |
| **Assigned file tree** | Which folder this workspace shows. Unset means all of them |
| **Home page** | A note (or plugin view) opened when you switch to it |
| **Starred notes** | Only the ones set with **Star for This Group** — the ordinary star is global. See [Starred notes](/organising/starred/) |
| **Visible** | Hide a pill from the strip without deleting it |
| **Active** | Inactive workspaces are excluded from the Navigator's combined view |

Set all of this up in **Preferences → Workspaces**.

<Image src={imgPrefsWorkspaces} alt="The Workspaces tab in Preferences, listing workspaces with colour, assigned folder and home page settings." />

## Visible vs. active

These sound alike and are not:

- **Visible** is about the pill strip. Hidden workspaces still take part in
  everything else — they are just not shown.
- **Active** is about search. An inactive workspace's files are excluded from
  the Navigator's combined "all files" view, but you can still select its filter
  pill directly and see them.

Deactivating is how you park a finished project without deleting it or having
its notes turn up in every search.

## A worked example

Three workspaces, one Mac:

| Workspace | Colour | Tree | Home page |
|---|---|---|---|
| Personal | amber | `~/Documents/Notes` | `Inbox.md` |
| Work | blue | `~/Work/notes` | `This week.md` |
| Archive | grey | `~/Archive` | — (inactive) |

Archive stays out of day-to-day searching but is one click away when needed.

## Themes that follow the workspace

Two of the sixteen themes — **Chromatic Dark** and **Chromatic Light** — take
their accent colour from the active workspace instead of a fixed palette. With
those selected, switching workspace re-tints headings, links and list markers,
so the colour tells you where you are.
