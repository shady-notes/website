## Where are my notes?

`~/Documents/ShadyNotes/` by default, as plain `.md` files. Change or add
folders in **Preferences → Vault**. →
[Vault and files](/concepts/vault-and-files/)

## Is it compatible with Obsidian?

Yes. Notes are plain Markdown with the same wikilink, embed and callout
conventions, so the same folder can be an Obsidian vault. Front matter is shared
too.

Obsidian plugins do not work here — Shady Notes has [its own plugin
format](/plugins/authoring/).

## Does it upload my notes?

No. Notes never leave your Mac. The only thing that goes online is an account
token, to check whether your plan is active. →
[Privacy and data](/help/privacy-and-data/)

## Does it work offline?

Yes. After a successful entitlement check the app works offline for 14 days
before re-checking. Everything else is local and always works.

## Is there a Windows or Linux version?

No. Shady Notes is a native macOS app — the shade, the menu bar behaviour and
the global hotkeys are built on macOS APIs. Because notes are plain Markdown,
you can read and edit them with anything on other platforms.

## Does it run on Intel Macs?

Yes. The download is a universal build for Apple Silicon and Intel. macOS 13 or
later.

## How do I export my notes?

Copy the folder. There is no export step, because there is no proprietary
format.

## How do I uninstall it?

Drag the app to the Trash, or `brew uninstall --cask shadynotes`. Your notes are
untouched — delete the vault folder yourself if you want them gone.

## What is free?

Everything except plugins, the thirteen non-default themes, and revision
history. No note limit. → [Licensing](/account/licensing/)

## Can I use it on more than one Mac?

Yes. Note that the trial is tracked **per machine**, so a second Mac starts its
own trial.

## Can I sync between machines?

Put the vault in iCloud Drive, Dropbox, or a git repo — Shady Notes has no
opinion. It detects outside changes and offers a three-way merge on conflict. →
[Conflicts](/history/conflicts/)

## Is there a mobile app?

No. Since notes are plain files, any iOS Markdown editor pointed at the same
synced folder works.
