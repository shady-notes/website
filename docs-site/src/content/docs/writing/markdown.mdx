additions of its own.

:::

## Text

| Syntax | Renders as |
|---|---|
| `**bold**` | **bold** |
| `*italic*` | *italic* |
| `` `inline code` `` | `inline code` |
| `~~strikethrough~~` | ~~strikethrough~~ |
| `==highlight==` | highlighted background |
| `[text](https://example.com)` | a clickable link |
| `[[wikilink]]` | a link to another note |

## Headings

```markdown
# Heading 1
## Heading 2
### Heading 3
#### Heading 4
##### Heading 5
```

Five levels, each scaled and weighted differently. <kbd>⌥⌘1</kbd> through
<kbd>⌥⌘5</kbd> apply them to the current line.

## Lists

```markdown
- Bullet item
* Also a bullet
1. Numbered item
```

Lists continue automatically on <kbd>Return</kbd>. Turn that off in
**Preferences → Editor** if you'd rather they didn't.

## Tasks

```markdown
- [ ] Unchecked
- [x] Checked
[ ] Standalone, no list marker needed
```

→ [Checkboxes](/writing/checkboxes/)

## Blockquotes and callouts

```markdown
> An ordinary blockquote.

> [!TIP]
> A typed callout, with an icon and colour.
```

→ [Callouts](/writing/callouts/)

→ [Tables](/writing/tables/)

## Images

```markdown
![alt text](path/to/image.png)
![[image.png|400]]
```

The second form is a wikilink-style embed with an explicit width in pixels.
→ [Images](/writing/images/)

## Emoji

Type `:name:` for an emoji, or `:name|32:` to set its size in points. `/emoji`
opens a picker.

## Horizontal rule

```markdown
---
```

## Front matter

A YAML block at the very top of a file is treated as metadata rather than
content:

```markdown
---
status: in-progress
tags: [docs, launch]
---
```

Plugins read these fields — the Kanban board builds its columns from `status`.
→ [Plugins](/plugins/overview/)
