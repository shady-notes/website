# Callouts

> [!NOTE]
> A callout is a blockquote with a type marker on its first line.

> [!TIP]
> Type `/callout` to insert one without remembering the syntax.

> [!SUCCESS]
> The docs site builds and deploys on every push to main.

> [!WARNING]
> Closing the shade resets its width back to the default.

> [!DANGER]
> Deleting a workspace removes its history, not just the tab.

> [!EXAMPLE]
> A type marker on the first line, then ordinary Markdown underneath.

> [!QUOTE]
> Notes should live in files you can still read in ten years.

> [!ABSTRACT]
> Nine types, each with its own icon and colour.

> [!QUESTION]
> Should callouts nest? They do, and they keep their own colours.

Type `/callout` on a blank line to insert one without memorising the list.
