# Welcome to Shady Notes

Your notes live **just above the screen**, a scroll away. Pull the shade down,
write, and let it roll back up.

Every note here is a plain `.md` file in your vault — open the same folder in
Obsidian, VS Code, or `vim` and nothing is locked away.

## Getting oriented

- [ ] Scroll down near the top of any window to open the shade
- [x] Click the pull tab to toggle it
- [ ] Press ⌥⌘S to show or hide the sidebar
- [ ] Press ⌘. for the slash-command picker

> Tip: `Esc` clears an active search first, and only then closes the shade.

See [[Markdown Reference]] for everything the editor renders.
